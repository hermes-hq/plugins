# Asset Licenses

## Rendering Engine Code

**Source:** [pixel-agents](https://github.com/pablodelucca/pixel-agents) by Pablo De Lucca
**License:** MIT
**Files:** `src/engine/`, `src/office/` (ported from `webview-ui/src/office/`)

The rendering engine (game loop, Canvas 2D renderer, BFS pathfinding, character
FSM, sprite cache, layout serializer) is ported from the pixel-agents VS Code
extension under the MIT license.

## Office Assets (Furniture, Floors, Walls)

**Source:** [pixel-agents](https://github.com/pablodelucca/pixel-agents)
**License:** MIT (explicitly open-sourced by the author)

The character sprites are described as "based on the amazing work of JIK-A-4,
